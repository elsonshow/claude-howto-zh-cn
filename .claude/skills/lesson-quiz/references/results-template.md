# 结果报告模板（Results Report Template）

这是 Step 5（评分并展示结果）的输出模板。使用时填充方括号里的占位符；标题、表格列和段落结构保持一致，正文用中文说明，关键英文术语保留。

```markdown
## 课程测验结果：[课程名称]

**Score: N/10（得分）** — [等级]
**测验时机**：[学前 / 学习中 / 学后]
**题型统计**：概念题正确 N 道，实践题正确 N 道

### 单题结果

| # | 类型 | 问题摘要 | 你的回答 | 结果 |
|---|------|----------|----------|------|
| 1 | 概念题 | [简写问题] | [用户选择] | [正确 / 错误] |
| 2 | 实践题 | ... | ... | ... |
| ... | ... | ... | ... | ... |

### 错题复盘

[每道错题都按下面结构展开：]

**Q[N]: [完整问题]**
- 你的回答：[用户选择]
- 正确答案：[正确选项]
- 解释：[为什么正确]
- 建议回看：[lesson README 的具体小节]

### 按测验时机给出的反馈

[如果是学前测验]：
**学前得分：N/10。** 这是学习前基线。重点学习上面错题对应的主题；完成本课后，建议再测一次看提升。

[如果是学习中检查]：
**阶段检查得分：N/10。** 如果 7 分及以上，说明进度不错，可以继续学；如果 4-6 分，先回看错题主题再往后走；如果低于 4 分，建议从本课开头重新梳理。

[如果是学后测验]：
**掌握度得分：N/10。** 如果 9-10 分，说明本课已掌握，可以进入下一课；如果 7-8 分，回看错题主题后重测；如果低于 7 分，建议重点复习上面标出的章节。

### 推荐下一步

- [如果已掌握]：进入路线图里的下一课：[下一课链接]
- [如果基本熟练]：回看这些具体小节后再测：[章节列表]
- [如果仍处于发展中或更低]：重新阅读完整 lesson：[课程链接]，重点关注：[薄弱类型列表]
- [后续选择]：重新测本课、测另一课，或解释某个未掌握的主题
```
